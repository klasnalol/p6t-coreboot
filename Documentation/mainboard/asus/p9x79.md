# ASUS P9X79

ASUS P9X79: LGA2011 desktop board, Intel X79 (C602) northbridge + PCH,
Nuvoton NCT6776F super I/O. Supports Sandy Bridge-E (Xeon E5/E7 v1,
CPUID `0x206d*`) and Ivy Bridge-E (CPUID `0x306e*`, e.g. i7-4930K)
processors. 4-channel DDR3 (1 DIMM slot per channel).

This port is in **Phase 1**: the ROM builds and the board should post, but
several subsystems run degraded or disabled. See *Known limitations* below.

## Flashing coreboot

```{eval-rst}
+---------------------+----------------+
| Type                | Value          |
+=====================+================+
| Socketed flash      | yes            |
+---------------------+----------------+
| Model               | W25Q64 (8 MiB) |
+---------------------+----------------+
| Size                | 8 MiB          |
+---------------------+----------------+
| Package             | DIP-8          |
+---------------------+----------------+
| Write protection    | no (family)    |
+---------------------+----------------+
| Dual BIOS feature   | no             |
+---------------------+----------------+
| Internal flashing   | yes            |
+---------------------+----------------+
```

The stock AMI BIOS applies no hardware write protection; flash the full
8 MiB image with `flashrom -p internal -w coreboot.rom` (boot with
`iomem=relaxed` if necessary).

## Hardware

| Component     | Device                                   |
|---------------|------------------------------------------|
| CPU           | LGA2011: SBE (0x206d*) / IBE (0x306e*)   |
| Northbridge   | Intel C602 (X79)                         |
| Southbridge   | Intel C602 PCH (bd82x6x driver)          |
| Super I/O     | Nuvoton NCT6776F (PnP 2e.x)              |
| Audio         | Realtek ALC898 HDA                       |
| Memory        | 4 x DDR3 DIMM, one per channel, max 1600 |
| PCIe          | 3 x CPU PEG groups (01.0/01.1/06.0)      |

The board lives under `src/mainboard/asus/p8x7x-series/` as the `p9x79`
variant, sharing the series devicetree, ACPI and Kconfig plumbing with the
P8C WS / P8H77-V / P8Z77-* boards.

## Building

```
make asus-p9x79_defconfig
make -j$(nproc)
```

(or select *ASUS -> P9X79* in `make menuconfig`).

## Known limitations (Phase 1)

- **DRAM: 2 of 4 channels, max DDR3-1066.** The in-tree native raminit for
  sandybridge models a 2-channel memory controller
  (`raminit_common.h: NUM_CHANNELS 2`) and its timing table tops out at
  DDR3-1333 with the effective clock clamped to 1066 MHz. The C602/IBE IMC
  is 4-channel (one slot per channel), so a fully populated P9X79 boots
  with only channels 0-1 active. Phase 2 will add a 4-channel path derived
  from the stock BIOS `IvtQpiandMrcInit` PEI module.
- **C602 PCH PCIe root ports are off.** The C602 exposes RPs at
  `10.0 (x4)` and `10.1-10.3 (x1)`, but the shared `bd82x6x` RP code is
  written for the C216/H77 `1c.x` layout, so those slots are not wired up.
  The three CPU PEG groups (primary GPU slots) are enabled; an untrained,
  unused PEG is harmless.
- **Audio: no verb table.** The HDA codec (ALC898) is probed but left with
  its default pin configuration, so there is no audio output until the
  verb table is decoded from the compressed HDA driver in the stock ROM.
- **VBT is a Sandy Bridge placeholder** copied from the P8C WS variant; the
  integrated graphics (HD 4000 on IBE) may not display correctly until an
  IBE VBT extracted from the stock ROM (BBVideo module) replaces it.
- **SBE microcode is not included.** Only Ivy Bridge-E microcode
  (`06-3e-*`, upstream `intel-microcode` repo) is packed into the ROM.
  SBE CPUs (0x206d*) are not in the CPU table; if support is wanted,
  `06-2d-*` patches must be sourced separately.
- **USB current/OC pin map** is a starting point copied from the P8C WS
  (same SIO family); over-current protection groups should be verified
  against the AMI `NBPEI` autoport sequence before trusting them.
- **SIO config**: the LD layout matches the stock ROM's `SIOBasicIOPei`
  module (PnP base `2e/2f`, LD select reg `0x07`; LDs 0x00–0x17 as in the
  overridetree). The stock ROM programs the NCT6776F hardware-monitor
  register space through the **`0x295`/`0x296`** window (bank reg `0x4E`;
  bank7 reg `0x09` = logical `0x709` = PECI0/CPU critical temp =
  Tjmax−10; bank4 regs `0x23`–`0x28` = fan/thermal control), so the HWMON
  LD base here is `0x295`, not the `0x290` default used by other boards.
  The ROM also does a SIO presence check through a second access path at
  `0x70`/`0x71` (regs `0x4F`, `0x8E`); its exact semantics are not yet
  decoded and it is not replicated. The ACPI LD PnP vendor register `0xF1`
  is written by the ROM depending on Setup NVRAM contents; it is left
  unconfigured here.

## Phase 2 roadmap

1. 4-channel DDR3 training: extract/adapt the MRC engine and DMI recipe
   from the stock `IvtQpiandMrcInit` PEI module (see `work/notes/` in the
   porting workspace) into a `raminit_mrc` path with a C602 `mrc.bin`.
2. C602 RP support (`10.0`-`10.3`) in the `bd82x6x` driver.
3. IBE VBT / VBIOS from the stock ROM `BBVideo` module.
4. HDA verb table from the compressed HDA driver in the stock ROM.
5. USB OC pin groups from the `NBPEI` autoport decode; slot -> PEG/RP
   wiring from GNVS/ACPI.
